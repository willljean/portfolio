# William Jean Portfolio
Static portfolio website built with HTML, CSS, JavaScript, and Bootstrap 5.

## Structure

- `index.html` — main page
- `css/styles.css` — custom styling
- `js/main.js` — navigation and sideways scroll behaviour
- `assets/` — logo and resume
- `projects/` — placeholder case study pages
